01 · 소개

이 프로그램이 뭔가요?

진로 월드컵은 학생들이 두 가지 선택지를 반복적으로 비교하면서 자신의 진로 기준과 관심 직업을 발견하는 브라켓 토너먼트형 진로 탐색 도구입니다. 스마트폰이나 PC 브라우저에서 HTML 파일 하나만 열면 바로 사용할 수 있어 설치가 필요 없습니다.

✅ 왜 효과적인가요?
  • 🧠정답이 없어 심리적 부담 없이 참여 가능
  • 🎮게임 형태라 학생 참여도가 높음
  • 📊결과 리포트로 Holland 코드·세특 초안 자동 생성
  • 🎥703개 탐색 영상 연동으로 추가 탐색까지 한 번에
  • 👩‍🏫세특 문장·상담 질문이 자동 생성되어 교사 업무 절감
💡
진로 검사와의 차이점 일반 진로 검사는 설문 응답으로 유형을 분류하지만, 진로 월드컵은 직접 선택하는 과정 자체가 탐색입니다. 결과보다 선택하는 이유에 주목하게 해주세요.
02 · 빠른 시작

5분 만에 시작하기

⚡ 즉시 시작 가이드

  1. 파일 열기 — 진로_월드컵_v3.html 파일을 Chrome 또는 Edge에서 열어요.
  2. 이름 입력 — 이름 칸에 학생 이름을 입력해요. (선택 사항)
  3. 모드 선택 — 처음이라면 💎 가치관 월드컵을 추천해요. 가장 쉽고 빠릅니다.
  4. 게임 진행 — 두 카드 중 더 끌리는 것을 터치·클릭! 이유도 골라주면 분석이 정확해져요.
  5. 결과 확인 — 결과 리포트에서 우승 직업, Holland 코드, 세특 초안을 확인하세요.
⚠️
권장 환경 Chrome 또는 Edge 브라우저를 사용해주세요. Safari는 일부 기능이 제한될 수 있습니다. 인터넷 연결이 필요합니다 (폰트·영상 링크 로딩).

04 · 수업 진행

수업 진행 흐름

50분 수업 기준 권장 흐름입니다. 학교 상황에 맞게 조절해주세요.

1
🎯 도입 (5분) — 오늘 활동 소개
"오늘은 두 가지를 비교해서 내가 뭘 좋아하는지 알아보는 활동이에요."
강조 포인트: "정답은 없어요. 지금 이 순간 솔직하게 끌리는 걸 고르면 돼요."
💡 Tip 교사가 먼저 시범을 보여주면 학생들의 참여 장벽이 낮아져요.
2
💻 모드 선택 & 시작 (3분)
학생들이 파일을 열고 이름을 입력한 뒤 교사가 지정한 모드를 선택해요.
처음이라면: 모두 동일한 모드(가치관 or 동사)로 시작하는 것이 비교·토론에 유리해요.
3
🎮 게임 진행 (15~20분)
학생들이 각자 게임을 진행해요. 이유 선택 버튼도 눌러보도록 안내해주세요.
교사 역할: 주변을 돌며 "이걸 왜 골랐어요?" 같은 가벼운 질문으로 자기 탐색을 도와주세요.
💡 Tip "이유 버튼도 눌러주면 분석이 훨씬 정확해져요"라고 한 번만 안내해도 효과가 있어요.
4
📊 결과 확인 & 성찰 (10분)
결과 화면에서 우승 직업, TOP4, 선택 이유 분석을 확인해요.
성찰 질문 버튼을 클릭하면 7가지 성찰 질문이 열려요. 모둠별 토론에 활용하세요.
💡 Tip "TOP4의 공통점은 뭐야?"라는 질문 하나가 수업을 풍성하게 만들어요.
5
💬 마무리 나눔 (10분)
몇 명의 학생이 결과를 발표하거나 스마트폰으로 친구에게 보여줘요.
교사는 교사용 정보 보기 버튼으로 학생 결과의 세특 초안을 바로 복사할 수 있어요.
✅
공용 PC 사용 시 꼭 확인! 학생이 게임을 마친 후 결과 화면 하단의 "🗑 내 활동 기록 지우고 나가기" 버튼을 눌러 다음 학생을 위해 데이터를 초기화해주세요.
05 · 결과 화면

결과 화면 읽는 법

결과 화면은 학생용 정보와 교사용 정보로 구성되어 있어요.

📋 결과 화면 구성
1
🏆 우승 직업
최종 선택된 직업 카드. 설명·카테고리·키워드 태그가 표시돼요. 탐색 영상 링크도 함께 제공됩니다.
2
🥇 TOP 4
준결승까지 살아남은 4개 직업. 우승 직업과의 공통점을 찾도록 안내해주세요.
3
📊 선택 이유 분석
학생이 선택할 때 가장 많이 누른 이유를 그래프로 보여줘요. 학생의 진로 기준을 파악하는 핵심 자료입니다.
4
🔬 Holland 코드 & 추천 학과
우승 직업을 기반으로 분석한 Holland 코드와 관련 전공 학과를 보여줘요.
5
💭 성찰 질문 (클릭하면 열려요)
결과를 바탕으로 생성된 7가지 성찰 질문. 모둠 토론이나 학생 성찰 글쓰기에 활용하세요.
★ v3 부활 기능
6
👩‍🏫 교사용 정보 (토글 버튼으로 열기)
상담 질문 3개, 세특 기록용 문장 초안, 선택 이유 빈도표가 포함되어 있어요. 세특 문장은 복사 버튼으로 바로 가져갈 수 있어요.
06 · 교사 전용 기능

교사를 위한 기능들

📝 세특 기록용 문장 자동 생성

결과 화면 → 교사용 정보 보기 → 세특 기록용 문장 초안 섹션에서 학생의 선택 패턴을 바탕으로 자동 생성된 세특 초안 문장을 확인할 수 있어요. '세특 문장 복사' 버튼으로 클립보드에 복사한 뒤 나이스에 붙여넣으면 됩니다.

📌
세특 초안 활용 방법 자동 생성 문장을 그대로 사용하지 말고, 학생과의 대화 내용, 추가 관찰 사항을 보완해서 사용하세요. 초안은 출발점일 뿐입니다!
💬 상담 질문 자동 생성

교사용 정보 탭에서 학생 맞춤 상담 질문 3가지가 자동으로 생성돼요. 1:1 진로 상담 전에 미리 확인해두면 대화를 풍성하게 이어갈 수 있어요.

🖨️ 인쇄 기능

결과 화면 우상단의 🖨️ 인쇄 버튼을 클릭하면 결과 리포트를 A4로 인쇄할 수 있어요. 포트폴리오·학생부 첨부 자료로 활용하세요.

📋 결과 복사

결과 화면 우상단의 📋 복사 버튼을 클릭하면 전체 결과를 텍스트로 복사해요. 학교 LMS나 구글 클래스룸에 붙여넣어 기록을 남길 수 있어요.

☀️ 라이트 / 🌙 다크 모드 전환

화면 오른쪽 상단의 ☀️/🌙 버튼으로 배경 색상을 전환할 수 있어요. 밝은 교실에서는 라이트 모드, 어두운 환경에서는 다크 모드를 추천해요.

07 · 활용 팁

수업 활용 꿀팁

상황추천 활동
1학년 첫 진로 수업 💎 가치관 월드컵으로 시작 → 모둠별 결과 공유 → "우리 반 가장 많이 뽑힌 가치관" 집계
진로 검사 후 연계 수업 🎯 검사 기반 맞춤형 모드에 커리어넷 결과 입력 → "검사 결과 vs 내가 직접 고른 직업" 비교

🎥
탐색 영상 활용하기 결과 화면의 유사 직업 카드에는 커리어넷·워크넷·유튜브 탐색 영상 링크가 연결되어 있어요. "이 직업이 실제로 어떤 일을 하는지 영상으로 확인해봐" 라고 안내해주세요. (인터넷 연결 필요)
08 · FAQ

자주 묻는 질문

학생 결과를 한꺼번에 모아볼 수 있나요? ▼
현재 버전에서는 기기별로 결과가 저장되기 때문에 한 화면에서 전체 학생 결과를 모으는 기능은 없어요. 대신 각 학생의 결과 화면에서 📋 복사 버튼이나 🖨️ 인쇄 버튼을 활용해 기록을 남기거나, 구글 폼과 병행해서 결과를 수합하는 방법을 추천해요.
스마트폰에서도 사용할 수 있나요? ▼
네! 모바일 최적화가 되어 있어 스마트폰에서도 편하게 사용할 수 있어요. 학생들이 자신의 폰으로 참여하면 동시에 진행이 가능해요. Chrome 앱으로 파일을 열거나, 교사가 파일을 서버에 올린 뒤 링크로 공유하는 방법도 있어요.
Holland 코드가 뭔가요? ▼
Holland 코드(RIASEC)는 직업 흥미 유형을 6가지(현실형·탐구형·예술형·사회형·기업형·관습형)로 분류하는 이론이에요. 진로 월드컵은 우승 직업을 기반으로 가장 연관된 Holland 코드를 자동으로 제안해줘요. 결과를 커리어넷 직업 흥미 검사와 비교해보면 더 풍부한 분석이 가능해요.
역 월드컵은 어떻게 활용하나요? ▼
역 월드컵은 "더 하기 싫은 것"을 선택해서 탈락시키는 방식이에요. 끝까지 살아남은 직업이 "가장 덜 싫은 직업" = 탐색 후보가 돼요. 진로가 전혀 없다고 말하는 학생, 또는 싫은 건 명확한데 좋아하는 건 모르는 학생에게 특히 효과적이에요.

시작 전 사전 조건 설정 화면에서 가장 싫은 근무 환경(야외근무, 야간근무 등)을 최대 3개 선택하면 해당 조건의 직업이 먼저 등장해서 탈락 패턴을 더 빠르게 파악할 수 있어요.
모드 시작 전에 팝업이 뜨는데 뭔가요? ▼
가치관·동사·직업군 월드컵을 시작하면 해당 모드의 규칙과 선택 팁을 안내하는 인트로 팝업이 나타나요. 4초 후 자동으로 닫히거나, "시작할게요 →" 버튼을 눌러 바로 게임을 시작할 수 있어요. 학생들이 선택 기준을 이해하고 시작할 수 있어 첫 선택의 혼란을 줄여줘요.
세특 초안을 그대로 써도 되나요? ▼
